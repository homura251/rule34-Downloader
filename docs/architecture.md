# 2.1 作者相册与下载流程

沿用六模块依赖：`app` 组装；`ui` 使用 Compose、ViewModel 和 Paging；`domain` 定义模型与接口；`download` 运行纯 Kotlin 下载状态机；`data` 实现 DAPI、Room 和设置；`platform` 负责 WorkManager、MediaStore、SAF 与通知。

## 交互与查询

主导航为作者、全部作品和下载，设置通过顶部打开。作者相册展示已发现作品，使用本地 URI 优先和在线预览回退。全屏预览直接访问同一 Paging 数据，保留占位计数与稳定作品身份，不复制当前内存中的图片快照。

全局图库按 Post ID 去重；失败查询以 `(collectionId, postId)` 为身份，跨作者不去重。失败分页读取现有 `download_tasks.error / attempts / updated_at` 并关联帖子元数据，显示文件名、作者、Post ID、预览及原因。下载器和列表共用 `DownloadFileName`。

添加标签无需联网预验证；帖子输入通过 API 识别作者，只有多作者才确认。重复标签打开已有相册。凭据保存只检查非空，服务端认证失败由实际请求报告，预览和已有媒体地址不因 API 认证失败被禁用。

## 下载与失败

扫描保留分页身份、边界和完整性检查；只有完整扫描提交水位。扫描失败仍处理已有文件，保留检查点并单独报告扫描状态。

下载不要求或计算 MD5，不读回 MediaStore 文件，不逐次重验已完成 URI。保留响应状态、HTML 识别、非空、已知长度、写入与取消处理。写入完成后在不可取消区间发布条目并保存 URI；发布后的数据库异常不删除已完成文件。

`SavedFile.verifiedMd5` 可空。旧校验值保留，新下载不把元数据哈希写成已验证结果。数据库结构和版本 7 不变，旧迁移保留已完成状态与 URI。

所有传输错误在退出运行前持久化到具体文件；网络、429 和临时服务端错误不增加永久错误次数，使用退避和 Retry-After。文件拒绝不累计成整组停止条件，其他文件继续。手动重试次数不受永久错误自动尝试上限限制。

`retryFiles(keys)` 只重置所选失败项，使用已有文件队列，不重扫作者。运行中的重试请求追加到每作者唯一工作链，避免请求丢失；暂停意图、文件模式、错误和检查点在重启后保留。批量重试跳过用户暂停的作者，单文件重试在暂停时入队等待继续。

## 文件复用与后台

已有 URI 或文件名身份可用于复用，检查可读、非空和已有长度；Post ID 与哈希文件名继续兼容。无法识别的任意改名文件不建立内容索引，也不删除。SAF 通过不透明 document ID 迭代遍历，检查取消与循环，不因固定层级或数量拒绝目录。

保留每作者运行租约、控制指令锁、实际目录互斥锁和 MediaStore 所有权处理。API 失效只改变元数据获取能力，不取消其他正在传输的媒体文件。显式保存或清除账号后重新安排任务，用户暂停状态保留。

## 验证

JVM 覆盖无哈希传输、长度检查、取消、分页检查点、认证故障隔离、连续文件失败和重试模式。真实 SQLite 覆盖旧版本迁移、跨作者失败身份、分页、选择性重试、错误持久化与过期运行写入隔离。Android 测试覆盖三入口、可选凭据、分页全屏预览、逐文件失败重试、MediaStore 发布、目录授权和旧文件复用。
